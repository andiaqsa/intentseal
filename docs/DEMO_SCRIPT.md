# IntentSeal Demo Script (60–90 seconds)

**0:00–0:12 — The promise**

“I define three things I promise to build: five login attempts per minute per IP, HTTP 429 when exceeded, and automated tests.”

Show the structured intent and canonical hash. Check the confirmation box.

**0:12–0:25 — Seal before**

Click **Seal intent on-chain**, approve MetaMask, and show the confirmed BOT Chain transaction.

“Now the promise exists before the implementation. I cannot rewrite it after seeing the result.”

**0:25–0:45 — Exact evidence**

Open **Evidence**, load the intent ID, enter the author-owned golden repository, and analyze its default branch.

“IntentSeal locks the finished work to this exact 40-character GitHub commit and shows deterministic evidence for every criterion. No AI provider or API key is involved.”

Show the status, file, line range, and excerpt for each criterion.

**0:45–1:02 — Review and seal after**

Open the canonical outcome, check the human-review confirmation, click **Seal reviewed outcome**, and approve MetaMask.

“Success appears only after the event and contract readback match the exact local outcome hash.”

**1:02–1:20 — Public proof**

Open **Public Proof** and point to the `BEFORE → EVIDENCE → AFTER` timeline.

“The intent existed at T1. The evidence is locked to one immutable commit. The outcome was recorded later at T2. IntentSeal proves chronology, integrity, and provenance—not absolute software correctness.”

End: **“Promise before. Evidence after. Proof forever.”**
